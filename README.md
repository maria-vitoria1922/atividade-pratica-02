# atividade-pratica-02

1. Para que serve disponivel ?
para ver se o livro está acessível para empréstimo ou se já foi emprestado
2. Por que usar session.commit() ?
Para confirmar e gravar permanentemente no banco de dados todas as alterações realizadas durante a sessão
3. Onde você usa o relacionamento Livro - Autor ?
O relacionamento entre Livro e Autor é usado nos modelos models.py via relationship e ForeignKey para associar cada livro ao seu respetivo autor e permitir as consultas
